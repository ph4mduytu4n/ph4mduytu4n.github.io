Distributed product-management database

Course project · team of three

A product and order database split across three Oracle sites. An order placed at any site is routed to the site that owns the product.

  • Oracle
  • PL/SQL
  • Database links
  • Triggers

What I did

  • Designed the fragmentation scheme and wrote most of the implementation; each teammate owned one site.
  • Horizontal fragments of Product and Orders by product_id range, so each site owns the orders for its own products.
  • Vertical fragments of Supplier: core fields on every site, contact details on Site 1 only.
  • Replication of Customer: one master, two local copies.
  • AddOrder forwards over a database link when the product lives elsewhere. Triggers compute order totals and keep each customer's total payment in sync.
  • Per-site tests plus a cross-site test that places an order at one site and checks it from another.

Flight Route Advisor

Python · Streamlit app

Finds routes between airports and studies the world's airport network, using the public OpenFlights data.

  • Python
  • NetworkX
  • Streamlit
  • Gephi

What it does

  • Route search: shortest route between two airports with Dijkstra, with optional limits on stops and route preferences.
  • Hub analysis: ranks airports worldwide or per country.
  • Hub removal: simulates closing a hub and reports how connectivity changes and which alternative paths remain.
  • Robust transfers: suggests alternative transfer hubs for a route.
  • Interactive maps in the Streamlit app, with the data pipeline and graph analysis kept in separate modules.
